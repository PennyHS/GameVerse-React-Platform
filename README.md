# GameVerse (React)

A gaming landing page built with React, Vite, GSAP, and Tailwind CSS, featuring scroll-triggered animations and a responsive layout.

**This version:** [Live demo](your-live-site-link)

> **HTML/CSS/JS version:** [Live demo](https://game-verse-react-platform.vercel.app/) · [Source code](https://github.com/PennyHS/GameVerse-HTML-CSS/)

## About

An interactive gaming website focused on smooth animations and modern UI design. This is a rebuild of my original vanilla HTML/CSS/JS version.

## Why React?

The original version used `animation-timeline: view()` for its scroll animations, which isn't supported in every browser. In this version, I replaced it with GSAP's ScrollTrigger, which gives consistent animations across browsers and more control over timing and sequencing.

## Features

- Scroll-triggered animations with GSAP
- Responsive layout
- Gaming-inspired UI
- Reusable React components

## Built With

- **React** – component-based UI
- **Vite** – build tool and dev server
- **GSAP** – scroll-triggered animations
- **Tailwind CSS** – utility-first styling
